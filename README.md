## 🚀 Featured Systems & Engineering Highlights

- 🛡️ **[Hardened Kubernetes Platform](https://github.com/nael0407/k8s-hardened-platform)**  
  *Triple-Layer Defense-in-Depth on Linux Kernel 6.8 with Cilium eBPF, Tetragon, Kyverno, and Cosign.*  
  Engineered zero-trust network isolation, supply-chain cryptographic validation, and sub-millisecond in-kernel threat termination (`SIGKILL`). Achieved a **100% pass rate across 9 MITRE ATT&CK audit vectors** with 0% false positives and automated GitOps deployment.

- 🌐 **[Data Center Micro-segmentation & DFIR Lab](https://github.com/nael0407/DataCenter_Network_MicroSegmentation_-_Lateral_Movement_Hunting)**  
  *Enterprise Zero-Trust (NIST SP 800-207) & DFIR on a 14-Node Spine-Leaf EVPN/VXLAN Data Center Fabric.*  
  Integrated OPNsense stateful firewalling with host nftables micro-segmentation via Ansible, reducing attack blast radius by **85.7%** and blocking **100% of multi-hop SSH pivots**. Built an automated ISO/IEC 27037 forensic RAM collection pipeline (**2.36s average collection**) and Zeek threat hunting graph.

- 🤖 **[Altair Humanoid Perception Pipeline (GMRT)](https://github.com/Altair-Humanoid-GMRT/altair_ws)**  
  *Autonomous Humanoid Soccer Robot Vision System (RoboCup / KRSBI Humanoid).*  
  Engineered real-time ROS2 perception modules achieving **97.7% mAP@50** multi-ball detection (RF-DETR & YOLO) and **~12 FPS** field segmentation under dynamic, adverse indoor arena illumination.

- 🎮 **[Tetris Deep Reinforcement Learning](https://github.com/nael0407/Tetris_DRL)**  
  *Empirical Factorial Research: Representation vs. Algorithm in Deep RL.*  
  Demonstrated feature representation determinism in Tetris (**55,169.2 IQM** on Dellacherie features vs. 0.0 on raw boards) across CEM and DQN. Built a custom Gymnasium environment accelerated via Numba JIT achieving **>10,000 steps/sec** CPU throughput with 66 passing unit tests.

- 📡 **[WiFi Network Performance Simulator](https://github.com/nael0407/Wifi-Simulation)** | [Live Demo](https://wifi-simulation.vercel.app/)  
  *Stochastic $M(t)/M/K/K$ Multi-Class Loss System & Wireless Propagation Engine.*  
  Interactive web simulation modeling theoretical queueing systems, log-distance path loss, and GPS/WFQ scheduling to prevent user starvation during bulk surges (+299.6% collaboration throughput). Built with React 18, Canvas rendering at sustained 60 FPS (~35k steps/sec), and 100/100 Lighthouse score.
